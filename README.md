# 灵动修炼录：运动修仙养成工具

一个纯前端 Web MVP，把大学生日常运动转化为修仙养成反馈：修为、灵石、体魄、境界突破、聚气丹、法宝和仙缘成就。当前界面采用主角居中的水墨洞府养成主界面，并在桌面端强化“主角中轴优先、修炼入口从属、资源信息退后”的层级，让用户首先是在养角色，其次才是记录运动。

## 运行方式

```bash
python -m http.server 5173
```

打开：

```text
http://localhost:5173
```

## 功能

- 洞府：首页仪表盘，展示境界、修为、灵石、连续修炼、本周历练和任务。
- 主角养成：支持男女双主角与短昵称，本地保存到 `cultivationQuestStateV2.user.character`；未设置昵称时显示“校园修士”。
- 修炼：手动记录运动类型、时长、强度和心得，并结算修仙收益。
- 日志：查看每次运动转化出的修为、灵石和体魄。
- 命格：查看灵根、境界、法宝、仙缘和修炼偏好。
- 丹药：有效修炼推进聚气丹进度，服用后增加修为。
- 数据迁移：自动从旧版 `sportQuestMvpState` 迁移到 `cultivationQuestStateV2`。
- v2 视觉：使用独立生成的横幅、角色、徽章、法宝和空状态图片，不再依赖单张资产表裁切。
- 结算反馈：修炼完成后显示收益卡、突破、法宝激活和仙缘解锁事件。
- 宗门周常：根据本周记录计算委托进度、宗门贡献和弟子段位。
- 周常副本：把宗门周常完成度转化为云阶试炼清剿率和关卡节点。
- 心魔挑战：根据今日修炼状态生成拖延、定心和连续节奏的小目标。
- 阶段剧情：根据境界、本周副本和心魔状态生成修炼篇章与剧情旁白。
- 法宝养成：根据运动类型累计法宝共鸣时长，展示阶位、技能描述和下一阶目标。
- 修炼报告：在命格页汇总累计表现、本周进度、偏好方式、最强法宝和下一步建议。
- 阶段称号：根据修炼次数、累计时长、连续天数、突破、周常和境界生成当前称号与称号进度。
- 仙缘筛选：支持按全部、已解锁、待解锁、修炼、连续、突破、收藏查看成就。
- 修炼周报：生成本周修炼总结文案，支持一键复制。
- 沉浸式界面：四个主视图重构为洞府场景、修炼阵台、修炼卷宗和命格阁。

## 文件说明

- `index.html`：洞府、修炼、日志、命格四个主视图。
- `styles.css`：洞府主界面、HUD 浮层、修炼阵台、卷宗和命格阁样式。
- `app.js`：修为结算、境界突破、丹药、法宝、仙缘、本地存储和旧数据迁移。
- `PRODUCT_PLAN.md`：产品定位、玩法循环和验收标准。
- `assets/images/`：由 `imagegen` 生成并压缩优化的项目美术资产。
